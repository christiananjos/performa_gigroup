# Frontend — React 18 + TypeScript (somente frontend)

Parte do monorepo (veja o `README.md` da raiz). O código desta frente fica em `frontend/src/`;
memória (`knowledge/`), agentes (`.claude/`), especificação (`docs/frontend/SPEC.md`) e relatórios
(`output/`) ficam na raiz.

## Como rodar

Todos os comandos rodam **de dentro desta pasta**:

```bash
cd frontend
npm install
npm run dev
npm test
```

## Pipeline

Para gerar ou alterar código aqui, rode na raiz do projeto: `/inicia-orquestracao frontend`.
